# ariadne-example — gil 실사용 예제

[gil](https://github.com/hyun06000/Ariadne)로 **UC Berkeley 1973 대학원 입학 성차별 논란**을
분석한 예제 저장소입니다. LLM 에이전트가 오토모드로 데이터를 분석하며 남긴 **사고의 커밋 그래프**를
그대로 보존합니다.

## 🔎 그래프 보기 (라이브)

👉 **https://hyun06000.github.io/ariadne-example/**

`gil viewer build`로 뽑은 자기완결 정적 그래프입니다. 노드를 클릭하면 각 스텝의 보고서(실제 숫자·표)가 열립니다.

## 이 예제가 보여주는 것

"입학이 여성에게 불리했는가?"를 데이터로 검증하는 과정에서, gil의 세 가지 미덕이 한 그래프에 담깁니다.

1. **막힘 → 되돌아감(backtrack)이 그래프에 남는다.**
   첫 가설 H1 *"전체 합격률 여성 30.4% vs 남성 44.5% = 성차별"* 은 학과 교란을 무시했기에
   **fail(죽은 잎, s5)** 로 기각됩니다. 성공만 남기는 깔끔한 이력이 아니라, **막다른 길이 왜 죽었는지가 보존**됩니다.

2. **작게 쪼개어 정복한다.**
   큰 질문 하나를 define → hypothesis → verify → analyze → success 스텝으로 잘게 나눕니다.
   조상 define으로 되돌아가 새 형제 가지 H2 *"학과로 층화하면?"* 를 뻗습니다(backtrack).
   층화 결과 **6개 학과 중 4개에서 여성 합격률이 더 높습니다** — 심슨의 역설.

3. **배포 순환이 계보로 남는다.**
   개발(분석) → 스테이징(엄밀 z-test) → 배포(봉인) 세 체인으로 국면이 이어집니다.

## 결론

집계 격차(여성 30.4% vs 남성 44.5%)는 차별이 아니라 **지원 학과 분포 차이**의 산물입니다.
남성은 합격률 높은 학과(A 64%·B 63%)에, 여성은 낮은 학과(C·E·F)에 몰렸습니다.
대형 학과 A에서는 오히려 여성이 통계적으로 유의하게 우위(z=+4.15, p<0.0001)입니다.
