# 문제 정의 — UC Berkeley 1973 입학에 성차별이 있었는가?

## 무엇을 푸는가
1973년 UC Berkeley 대학원 입학 데이터로 "여성 지원자가 성별을 이유로 불리했는가?"를 검증한다.

## 입력 데이터 (`data/ucb_admissions.csv`)
6개 학과(A–F) × 성별(Male/Female)의 합격/불합격 수. 총 12행.

| 컬럼 | 의미 |
|------|------|
| Dept | 학과 A–F |
| Gender | Male / Female |
| Admitted | 합격 수 |
| Rejected | 불합격 수 |

## 평가 지표
합격률 = Admitted / (Admitted + Rejected). 성별 간 격차를 본다.

## 분석 관점 (두 갈래)
- **관점 1 (집계)**: 성별 전체 합격률만 비교한다.
- **관점 2 (층화)**: 학과별로 나눈 뒤 성별 합격률을 비교한다 (교란변수 통제).

## 제약 / 주의
학과는 잠재적 교란변수다. 지원 학과 분포가 성별로 다르면 집계 결과가 왜곡될 수 있다 (심슨의 역설 위험).
