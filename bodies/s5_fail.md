# 기각 — H1은 교란변수(학과)를 무시했다 (죽은 잎)

## 왜 기각하는가
집계 격차(30.4% vs 44.5%)는 **인과가 아니다**. 학과별 지원 분포를 통제하지 않았다.

관찰: 학과마다 합격률이 극단적으로 다르다.

| 학과 | 전체 합격률 |
|------|-------------|
| A | 64.4% |
| B | 63.2% |
| C | 35.1% |
| D | 34.0% |
| E | 25.2% |
| F | **6.4%** |

그리고 성별 지원 분포가 학과별로 크게 쏠린다:

| 학과 | 여성 지원 | 남성 지원 |
|------|-----------|-----------|
| A (쉬움) | 108 | **825** |
| B (쉬움) | 25 | **560** |
| C | **593** | 325 |
| E | **393** | 191 |
| F (어려움) | 341 | 373 |

남성은 합격률 높은 A·B에 몰렸고, 여성은 경쟁 심한 C·E·F에 몰렸다. 집계 격차는
**"여성이 어려운 학과에 더 많이 지원했다"**는 자기선택으로 상당 부분 설명된다.

## 결론
H1(집계 격차 = 성차별)은 교란을 통제하지 못한 잘못된 추론. **기각 → 조상 define(s2)으로 backtrack.**
